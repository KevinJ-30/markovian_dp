\paragraph{Source and splits.} All four are loaded from the GraphSAINT authors'
released files (\texttt{adj\_full.npz} / \texttt{adj\_train.npz} /
\texttt{role.json} / \texttt{feats.npy} / \texttt{class\_map.json}), not from
PyG, because they are not the same graphs: PyG's Reddit has 57{,}307{,}946
undirected edges against GraphSAINT's 11{,}606{,}919. Arc counts above are
measured after binarizing the released (row-normalized) matrices and dropping
self-loops. Splits measured from \texttt{role.json}:

\noindent PPI-large and Reddit reproduce Table 1 exactly --- PPI-large's
793{,}632 undirected edges plus its 25{,}084 self-loops are precisely the
818{,}716 reported. \textbf{Yelp and Amazon do not:} Amazon's released graph has
1{,}569{,}960 nodes against the paper's 1{,}598{,}960, and both differ in split
ratios. We report the file statistics, since those are what we actually run on.
