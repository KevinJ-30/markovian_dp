\section{Setup}
\label{sec:setup}

One SparseGNN step: each node is a root independently with probability
$p_1$; each root's neighborhood grows along \emph{incoming} edges for $r$
hops, keeping each edge independently with probability $p_2$
(\textsc{SparseExpand}$_{\mathrm{in}}$); each rooted subgraph contributes one
gradient $g_0$ (two-layer SAGE-mean or GCN), clipped to $\|g_0\|_2 \le C$;
clipped gradients are summed and $\mathcal N(0, (\sigma C)^2 I)$ is added.
$\sigma$ is the noise multiplier.

$K_{\mathrm{in}}, K_{\mathrm{out}}$ capped on both the training graph and the
union graph. $\delta = n^{-1.01}$, full node count. Training uses the
degree-capped graph; evaluation defaults to the full graph.

Blind arm = same mechanism at $r{=}0$, not a separate MLP.

PPI and RelBench are natively inductive. ogbn-arxiv/Flickr/Reddit are made
inductive by dropping cross-split edges.

\section{Results so far}
\label{sec:results-have}

$+1.5$ ($\varepsilon{=}1$) to $+4.1$ pts ($\varepsilon{=}8$).

result so far.

\subsection{user-churn}
GNN AUROC 0.55--0.56 vs.\ blind 0.49--0.51 (chance) at every $\varepsilon$.
$\varepsilon$ trend runs backwards (0.563$\to$0.551 as $\varepsilon$
$1\to8$) -- rerun with dropout/weight-decay on in progress, suspect the
zero-regularization setup is letting DP noise double as an accidental
regularizer.

\subsection{Not clearing trivial}
item-sales, user-ltv: no arm beats trivial MAE (0.0761, 16.78), DP or
non-DP. Heavy-tailed target, log-transform not yet tried. ad-ctr: non-DP
beats trivial (0.0426 vs 0.0522) but only 5{,}100 train rows forces
$\sigma$ up to 570 -- same row-starvation as rel-trial.

\subsection{Inconclusive}
author-category (11-way, rel-arxiv): everything lands at 0.09--0.10 vs.\
trivial 0.0909, 1 seed. Noise, not signal, until reseeded.
